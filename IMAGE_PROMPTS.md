# 🎨 MARK LX — Master Image Prompts (for Gemini image generation)

Copy-paste prompts for making logos, HUD mockups, posters and diagrams of
**JARVIS — MARK LX**.

**How to use:** open the Gemini app (or Google AI Studio) and use an *image*
model — commonly called **Nano Banana** / `gemini-2.5-flash-image`. Paste one
prompt, or type `Generate an image:` then the prompt.

---

## ⚙️ Read this first (3 rules that decide whether the picture looks good)

1. **Aspect ratio — say it in words.** Always add one line: `16:9 widescreen`,
   `1:1 square`, `9:16 vertical poster`, or `1280x640 banner`.
2. **Text in images — keep it short and quote it.** Write
   `the text reads exactly "MARK LX" and nothing else`. Long sentences garble.
   For diagrams: **maximum 6–8 short labels**, one or two words each.
3. **Consistency — reuse the same STYLE DNA block** (section 1) at the end of
   every prompt. Same palette + same lighting = a matching set. If Gemini drifts,
   attach a previous image and say
   `Same style, same colors, same character. Change only the background.`

## 12. 🎛️ Modifier matrix — swap one phrase, get a new picture

Append any of these lines to change the mood without breaking the set.

| Want | Add this line |
|---|---|
| Poster art, not photo | `flat vector illustration, bold shapes, minimal shading, no photorealism` |
| Blueprint / engineering look | `technical blueprint style, thin white-on-deep-blue line work, dotted measurement guides` |
| Phone wallpaper | `vertical 9:16 wallpaper, subject low and centered, large empty dark area at the top` |
| Instagram square | `1:1 square, subject centered with equal margins on all sides` |
| Bright daytime | `soft neutral daylight studio, light gray background, cool shadows` |
| Dramatic | `high contrast rim lighting, deep shadows, single cyan light source from the side` |
| Isometric tech | `isometric 3D render, 45 degree tilt, subtle depth of field, matte materials` |
| Animated-feel still | `dynamic motion blur trails on the light elements, frozen mid-motion` |

## 13. 🔁 Iteration lines (say these to fix a result)

| Problem | Say to Gemini |
|---|---|
| Text is misspelled | `Keep the entire image identical. Change only the text so it reads exactly "MARK LX".` |
| Too busy | `Keep the same style and colors but remove all small clutter and leave more empty dark space.` |
| Wrong colors | `Recolor only the glow elements to cyan #00d4ff. Change nothing else.` |
| Character/style drift | `Match this reference image exactly: same character, same palette, same lighting. Only the background changes.` |
| Too realistic vs vector | `Make it flat vector, remove photorealistic shading and reflections.` |
| Cropping | `Recompose for 16:9 widescreen with the subject centered and safe margins.` |

## 15. ⚠️ Two honest warnings

1. **Diagrams with many labels are the hardest thing for image models.** If the
   text garbles, ask for the picture *without* text and add labels yourself in
   Canva / PowerPoint / Paint.
2. **Never feed real API keys, tokens or personal photos into an image prompt.**
   Prompts go to Google's servers. Keys stay in `config/api_keys.json` only.
